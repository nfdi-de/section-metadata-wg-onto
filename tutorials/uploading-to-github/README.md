# Upload Tutorial

GitHub has a nice tutorial on uploading files
https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository.

This is a step-by-step reproduction.

## Step 1 - Navigate to Correct Folder

The first step is to navigate to the folder where you want to upload a file
through the GitHub interface. You can start at
https://github.com/nfdi-de/section-metadata-wg-onto and navigate like a file
browser.

When you're in the folder where you want to upload the files, look in the
top-right part of the window for the "Add File" button. It will give a
drop-down.

![](1.png)

## Step 2 - Click "Upload Files"

Click the "Upload Files" to bring to the next window, where you can drag and
drop files from your computer into the web browser window.

![](2.png)

## Step 3 - Drag Files

On this window, you can drag the Markdown (or other) files into the browser.
Note that they will retain the name from on your computer, so you might want to
rename them before dragging.

![](3.png)

## Step 4 - Scroll Down

After dragging in the files, scroll down to the box below the well which has the
header "Commit Changes".

![](4.png)

## Step 5 - Make New Branch

GitHub has a "branching" model, which means there are multiple copies of the
repository at once. This allows for multiple people to work in parallel. When
you're adding your new file, we want to simultaneously create a new branch.

Therefore, click the "Create a new branch" radio box

![](5.png)

## Step 6 - Name New Branch

It's helpful for people reading through the list of branches for your branch to
have a good name. By default, it uses your GitHub username, the word "patch",
and a number. If you can think of a better short name (lowercase, use dashes
instead of spaces), then change it now. Otherwise, the default is alright.

Then, you're ready to press the big green "Propose changes" button. This will
bring you to the next window.

![](6.png)

# Step 7 - Name PR

![](7.png)

You're now on a new page - this one creates a pull request with the branch you
just created. A pull request is the place where the WG can have discussions
about the changes. First, rename the title to something human-readable. If you
want to give more context, you can fill in the box under "Add a description".

Then, scroll down.

## Step 8 - Submit

Press the "Create pull request" green button to finish!

![](8.png)
